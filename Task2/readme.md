# Хранение данных
- внедрение Data Minimization
- локализыция данных (требование 152-ФЗ)
- тэгирование данных
- создание резервных хранилищ 

# Периоды и условия уничтожения конфиденциальных данных после обработки
- уничтожение данных после 5 лет неактивности пользователя либо по требованию 
- архивирование данных сроком на 5 лет 
- автоудаление времееных данных

# Способы защиты данных при хранении и передаче
- взаимодействие через https
- шифрование данных TLS 1.2+
- применение RBAC/ABAC, двухфакторная автоирзация
- система монитоинга и алертинга на несанкционированный доступ
- обезличивание данных при работе с BI
- маскирование данных
